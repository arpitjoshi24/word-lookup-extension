# Word Lookup — Synonyms & Antonyms

A simple Chrome extension: type any word, get its synonyms and antonyms.
Uses the free [Datamuse API](https://www.datamuse.com/api/) — no API key or sign-up needed.

## How to install (Chrome / Edge / Brave)

1. Unzip this folder somewhere on your computer.
2. Open `chrome://extensions` in your browser.
3. Turn on **Developer mode** (toggle, top-right).
4. Click **Load unpacked**.
5. Select the unzipped `word-lookup-extension` folder.
6. Pin the extension (puzzle-piece icon in the toolbar → pin "Word Lookup").

That's it — click the icon, type a word, hit Search.

## Features

- Synonyms and antonyms for any word
- Click any result chip to instantly look that word up too
- Keeps your last 10 searches for quick re-access
- Works fully offline of your own data — only talks to the Datamuse API

## Notes

- If a word has no listed antonyms, you'll see "None found" — not every word has one.
- If Datamuse has no direct synonyms, the extension automatically falls back to "words with a related meaning."
